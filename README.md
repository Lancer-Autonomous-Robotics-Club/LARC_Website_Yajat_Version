# LARC Website - Yajat Version


Official website for the **Lancer Autonomous Robotics Club (LARC)** at the University of Windsor — built by Yajat.


🌐 **Live site:** [larcwebsiteyajatversion-mpb9q8ozt-adam-elhajj.vercel.app](https://larcwebsiteyajatversion-mpb9q8ozt-adam-elhajj.vercel.app)


## 📁 Structure
- `index.html` — Homepage


- `assets/` — Images and media
- `css/` — Stylesheets
- `js/` — JavaScript


## 🚀 Run locally
Open `index.html` in a browser, or serve the folder with:


```
npx serve .
```
